# Rocket Academy Coding Bootcamp: Project 4 - Bow Wow Bistro

## Available Scripts

This project was created using with Vitejs. In the project directory, please run the following commands:

`npm install`
`npm run dev`

The second command will run the app To see the rendered output please open http://localhost:5173 in the browser of your choice, EG: Google Chrome.

The page will reload when you make changes. You may also see any lint errors in the console.

------

Welcome to Bow Wow Bistro! This is the frontend of a sample restaurant website for dogs (and dog owners too, I guess).

How to use:
1. If you don't have one already, create a Google account to test the app. 

For security reasons, please use your own account or create a new one specifically for testing purposes. If you'd like to use a test account instead, do message me for the details.

2. Click the Login/Signup page to be redirected via OAuth. Use your testing account.

3. After you've been redirected back to the main page, click on the menu page and add meals to your cart or click the Edit icon to subtitute the ingredients in those meals!

To subsitute, click on the ingredient you don't want in your meal, and click on the ingredient that you want on the right. Press the Subtitute icon to switch these ingredients. Press the + symbol after subsituting an ingredient to add it to your cart!

4. Checkout your cart's contents by clicking on Cart, then clicking the Checkout button.

Stripe is in test mode, so it won't deduct any actual money from your account.
